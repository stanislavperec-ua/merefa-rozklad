# Розклад електричок Харків – Мерефа

Telegram Mini App + бот + парсери офіційного розкладу УЗ. Як усе влаштовано: `README.md`.
Історія рішень і граблі: `../CONTEXT.md` (лежить поруч із репозиторієм, у git його немає).

## Мова проєкту: українська

Коментарі в коді, повідомлення логів, тексти помилок, рядки інтерфейсу, README і
повідомлення комітів пишемо українською. Це свідомий виняток із загального правила про
англійську в репозиторіях (рішення власника 08.10.2026): проєкт від початку український,
і часткове переписування дало б суміш двох мов в одному файлі.

## Команди

```bash
python -m unittest discover -s tests -q                     # усі тести: 91, близько 90 с
python -m unittest tests.test_fast tests.test_fast_api -q   # швидкі: 59, близько 22 с, без мережі
```

Mini App локально: `python -m http.server 8765` у цій папці (з `file://` fetch не працює).
Тести мережі не потребують: сторінки УЗ беруться з `tests/fixtures`, GitHub підмінений.

## Що розгортається саме, а що руками

| Частина | Як оновлюється |
|---|---|
| бот (`bot.py`, `gateway.py`, `fastbuild.py`, парсери) | Render сам, на кожен коміт у `main` |
| Mini App (`index.html`) | GitHub Pages сам, на кожен коміт |
| воркер (`worker.js`) | **руками**: коміт нічого не розгортає, треба залити через API Cloudflare (порядок у README, граблі в CONTEXT.md) |

## Чого робити не можна

* **Не правити руками `schedule.json`, `live.json`, `trains_cache.json`.** Це дані, які бот
  пише в GitHub сам; ручна правка обернеться конфліктом при наступному коміті бота.
* **Не пушити неперевірений код у `main`.** Render розгортає кожен коміт автоматично, тож
  помилка потрапляє в живого бота за сорок секунд. Перед push ганяємо принаймні швидкі тести
  (нижче є хук, який робить це сам).
* **Не друкувати секрети.** `BOT_TOKEN`, `GH_TOKEN`, `FAST_TOKEN` живуть у змінних оточення
  Render і в секретах воркера, у відповідях і файлах їм не місце.
* **Нічого не міняти на комп'ютері власника** (служби, реєстр, планувальник): усе, що треба
  запустити, запускається у фоні й без вікон на екрані.

## Хук «швидкі тести перед push»

`tools/pre_push_tests.py` отримує подію `PreToolUse`, і якщо Claude збирається виконати
`git push`, спершу ганяє швидкі тести. Падіння зупиняє push і показує, що саме зламалося.
Разово пропустити: `SKIP_PUSH_TESTS=1`.

Папка `.claude/` у git не потрапляє (див. `.gitignore`), тому хук вмикається локально, у
`.claude/settings.json` тієї папки, з якої відкрито сесію:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "python \"C:/Users/User/projects/Расписание электричек/merefa-rozklad/tools/pre_push_tests.py\"",
            "timeout": 300
          }
        ]
      }
    ]
  }
}
```

Шлях саме повний: хук виконується в поточній папці оболонки, а вона змінюється протягом
сесії, тож відносний шлях ламається (перевірено 08.10.2026: `merefa-rozklad/tools/...`
перетворився на `merefa-rozklad/merefa-rozklad/tools/...` і заблокував усі команди Bash,
бо python на ненайдений файл виходить з кодом 2, а це для хука означає «заборонити»).
Кирилиця в шляху працює, лапки потрібні через пробіл у назві папки.

## Коротко про архітектуру

Сайт УЗ не пускає великі хмари, тому сторінки качає Cloudflare Worker (або телефон власника
через Mini App), а бот на Render їх лише розбирає і комітить у GitHub. Розклад оновлюється
о 06:00 і 13:00 за Києвом, канал УЗ із затримками читається кожні 25 хвилин. Будильників
два незалежних: Cron Trigger воркера і пінг UptimeRobot у бота; GitHub Actions лишається
запасним шляхом і регулярно пропускає запуски.
